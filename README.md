# Python Daily Practices

一个按编号持续积累的 Python 实践仓库，收录 100 个独立练习脚本及配套示例数据。内容从基础语法逐步延伸至算法实现、面向对象建模、文件与数据处理、正则表达式和中英文文本分析，重点展示如何把语言特性应用到具体问题中。

## 项目概览

本仓库以“一题一文件”的方式组织练习，每个脚本都可以独立阅读和运行。题目覆盖的不只是基础语法，还包含可复用的函数设计、类与对象建模、目录遍历、CSV 处理、词频统计等常见开发场景。

- **100 个练习脚本**：按难度和主题逐步推进，便于按顺序学习或单独查阅。
- **13 个示例数据文件**：用于文件读取、成绩统计、数据关联和文本处理练习。
- **多种编程范式**：包含过程式脚本、函数封装、类与继承、异常处理及标准库应用。
- **完整知识链路**：从输入输出和流程控制延伸到文件系统、正则匹配与自然语言文本分析。
- **面向实践的运行示例**：涵盖 Tkinter 图形绘制、命令行小游戏、银行账户、购物车和聊天室等场景。

## 技术要点

### 标准库应用

练习覆盖 `collections`、`copy`、`csv`、`datetime`、`calendar`、`math`、`os`、`random`、`re`、`shutil`、`string`、`time` 和 `tkinter` 等常用标准库。例如：

- 使用 `Counter` 统计文本或人名出现频率。
- 使用 `csv` 完成结构化数据的读取与备份。
- 使用 `os` 和 `shutil` 遍历目录、汇总文件大小并整理文件类型。
- 使用 `datetime`、`calendar` 和 `time` 完成日期计算、日历输出与耗时测量。
- 使用 `re` 完成格式验证、字段提取和文本清洗。

### 第三方库扩展

- `pandas`：将英文分词结果转换为 `Series` 并进行高频词统计。
- `jieba`：中文分词及基于词性标注的人名识别。
- `python-dateutil`：解析非严格格式的日期字符串。

## 快速开始

### 环境要求

- Python 3.12 或更高版本
- Tkinter 图形练习需要 Python 安装中包含 Tk 支持

### 安装依赖

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

macOS / Linux：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

### 运行练习

本仓库没有统一的程序入口，可以直接运行任意编号脚本。例如：

```powershell
python .\1计算两数之和.py
python .\57数字猜谜游戏.py
python .\99中文文本分词.py
```

部分脚本通过 `input()` 接收终端输入；Tkinter 练习会打开独立绘图窗口；涉及文件处理的脚本应结合实际数据路径和目录结构调整后再运行。

## 运行注意事项

- 部分文件练习保留了原始 Windows 绝对路径（例如 `76–89` 中的部分脚本），在不同电脑上运行时需要改为本机路径或相对路径。
- `80按文件后缀名整理文件夹.py` 会移动目标目录中的文件，运行前应确认目录位置并做好备份。
- `84批量合并文本文件.py` 会生成合并后的输出文件，请先检查输入和输出目录。
- 示例中的姓名、手机号、密码和成绩均仅用于演示，不应视为真实的敏感数据。
- 源码文件使用中文命名，执行命令时请确保终端使用 UTF-8 编码。

## 学习与实践价值

这个仓库呈现了从“写出结果”到“组织可维护代码”的练习过程：前期关注语法、输入输出和流程控制，中期练习算法抽象与数据结构选择，后期则把函数和类应用到文件系统、结构化数据与文本分析任务中。对于正在学习 Python 的读者，可以按编号顺序练习，也可以根据主题表快速定位感兴趣的模块。
